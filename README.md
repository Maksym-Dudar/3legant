# 3legant

## Description

3legant is a modern e-commerce frontend application built with Next.js and TypeScript. The project delivers a fast, responsive, and user-friendly shopping experience while following modern development practices and scalable architecture.

## Functionality

- Browse products by categories
- Product search and filtering
- Product details page with image gallery
- Shopping cart management
- Wishlist functionality
- Responsive design for desktop and mobile devices
- User authentication and profile management
- Checkout flow
- Modern UI with smooth animations and sliders

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Redux Toolkit
- React Hook Form
- Zod
- Axios
- Swiper
- ESLint
- Prettier

## Run Locally

Clone the repository:

```bash
git clone https://github.com/Maksym-Dudar/3legant.git
```

Navigate to the project directory:

```bash
cd 3legant
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open your browser and visit:

```
http://localhost:3000
```
